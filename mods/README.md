# Моды для Claude Code

Четыре небольших мода: меняют, как выглядит и работает Claude Code. Мод — это плагин Claude Code, он работает только в Claude Code (терминал, приложение, VS Code, мобильное приложение), в обычном чате claude.ai не работает.

| Мод | Что делает |
| --- | --- |
| `team` | Панель «Команда» (`/team`): участники сессии и сообщения между ними. `/team-run <запрос>` запускает конвейер из трёх агентов: поиск компаний, письма, проверка. Письма не отправляются. |
| `model-router` | Перед каждой задачей оценивает сложность и выбирает Haiku, Sonnet или Opus, показывая выбор и причину. `/router off` выключает. |
| `morning` | Панель «Доброе утро» (`/gm`): дела, письма для ответа, проекты с прогрессом. `/todo`, `/mail`, `/project` для ручного ввода. |
| `helpers` | Счётчик трат за день (`/spend`), кнопка «Следующий шаг», напоминание сохранить работу перед опасной командой. |

## Установка

В терминальной сессии Claude Code:

```
/plugin install team --marketplace vanka122/github-slideshow
```

Вместо `team` подставь `model-router`, `morning` или `helpers`. На вопрос о добавлении маркетплейса ответь `y`, затем выбери область (scope).

Из оболочки: `claude plugin install team --marketplace vanka122/github-slideshow`.

В приложении, где `/plugin` не работает: нажми + рядом с полем ввода, затем Plugins, Add marketplace, `vanka122/github-slideshow`, потом Add plugin.

## Безопасность

Моды из интернета ставь только после проверки: попроси Claude прочитать код мода и объяснить, что он делает. Если мод мешает, попроси Claude его выключить.
