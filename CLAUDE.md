# CLAUDE.md

## Плагины

В этом проекте включены плагины Claude Code (см. `.claude/settings.json`):
claude-mem (память между сессиями), task-observer (улучшение скиллов) и headroom (сжатие контекста).

Используй скилл task-observer во время работы: отмечай мои правки, предпочтения и повторяющиеся просьбы
и предлагай улучшения скиллов. Ничего не меняй в скиллах без моего подтверждения.
